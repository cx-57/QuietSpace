# QuietSpace demo narration

The accompanying `artifacts/quietspace-demo.webm` is actual browser footage, roughly 2–3 minutes, silent with editorial captions. Reporting scenes explicitly use synthetic data in a separate PostgreSQL database. No fabricated observations were added to real venue records. Uploading/submitting the recording has not been performed.

**Opening, 0:00–0:15.** “Finding a suitable public place can take more research than the visit itself. I saw friends spend time looking for places that suited their attention and sensory needs, only to arrive somewhere distracting. QuietSpace helps make that choice more informed.”

**Preferences, 0:15–0:30.** “Choose the noise, crowd, brightness and scent levels that matter to you. You can leave anything unset. These choices stay in this browser. You do not need an account, diagnosis or device location.”

**Directory, 0:30–0:45.** “We’re starting with five real Boston library locations. Each has an official source and a review date. There are no invented community observations in this directory.”

**Strict filters, 0:45–0:55.** “If step-free access is required, unknown does not pass. A source-confirmed entrance does not prove the rest of the building is step-free. It is better to show no result than make an unsupported promise.”

**Evidence, 0:55–1:15.** “Details separate sensory observations, facilities and source facts. Fit needs enough recent approved observations, including noise and another dimension. Historical periods use the venue’s local time. Without enough data, the answer is unknown.”

**Sample report, 1:15–1:35.** “For this part of the demonstration we switch to an explicitly synthetic sample venue in a separate test database. A structured report records a visit time and sensory intensities. It never asks for personal comments or medical details.”

**Pending receipt, 1:35–1:50.** “The report is stored in real PostgreSQL as pending. Database policies hide it from public observations. A trusted operator, rather than the visitor or a public approval endpoint, must review it.”

**Approved evidence, 1:50–2:05.** “After operator approval, the sample report joins the evidence. Three approved observations now support a score for this test venue. The score describes preference fit, not confidence or current conditions.”

**Closing, 2:05–2:20.** “QuietSpace combines a usable neighborhood guide with honest uncertainty, private preferences and moderated contribution. It is built with Next.js, TypeScript and PostgreSQL, with AI coding assistance disclosed. The next step is a verified public deployment and feedback from consenting users.”

Timing is approximate; the actual recording includes navigation and load time. Review the video before upload. Do not narrate a public launch, user study, predicted quietness or clinical result that has not happened.
