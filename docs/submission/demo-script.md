# QuietSpace demo narration

The accompanying `artifacts/quietspace-demo.webm` is actual browser footage, roughly 2–3 minutes, silent with editorial captions. Reporting scenes explicitly use synthetic data in a separate PostgreSQL database. No fabricated observations were added to real venue records. Uploading/submitting the recording has not been performed.

**Opening, 0:00–0:15.** “Finding a suitable public place can take more research than the visit itself. I saw friends spend time looking for places that suited their attention and sensory needs, only to arrive somewhere distracting. QuietSpace helps make that choice more informed.”

**Quiet first-use, 0:15–0:35.** “Choose Find a Quiet Study Space to prioritize two Boston library locations with officially documented study areas. Bates Hall at Central Library and East Boston's quiet/study rooms are source-supported options—not decibel readings or real-time claims. You can also adjust noise, crowd, brightness and scent preferences, which stay on this device.”

**Directory, 0:35–0:50.** “We start with five real Boston library locations. Each has official sources and review dates. No community noise data is invented, and numeric scores stay unknown until enough approved reports exist.”

**Strict filters, 0:50–1:00.** “If step-free access is required, unknown does not pass. A source-confirmed entrance does not prove the rest of the building is step-free. It is better to show no result than make an unsupported promise.”

**Evidence, 1:00–1:20.** “Details separate sensory observations, facilities and source facts. Fit needs enough recent approved observations, including noise and another dimension. Historical periods use the venue’s local time. Without enough data, the answer is unknown.”

**Sample report, 1:35–1:55.** “For this part of the demonstration we switch to an explicitly synthetic sample venue in a separate test database. A structured report records a visit time and sensory intensities. It never asks for personal comments or medical details.”

**Pending receipt, 1:55–2:10.** “The report is stored in real PostgreSQL as pending. Database policies hide it from public observations. A trusted operator, rather than the visitor or a public approval endpoint, must review it.”

**Approved evidence, 2:10–2:25.** “After operator approval, the sample report joins the evidence. Three approved observations now support a score for this test venue. The score describes preference fit, not confidence or current conditions.”

**Community, 2:25–2:45.** “The Community page shows real report counts, highlights where firsthand experiences are still needed, and invites people to suggest other public spaces for source review. Here are the approved structured community reviews; with no reports, it deliberately shows zero. The moderation workflow, shown with an explicitly synthetic test venue, is what makes this trustworthy.”

**Closing, 2:45–2:55.** “QuietSpace is designed to become more useful as neighbors contribute. It uses Next.js, TypeScript and PostgreSQL, with AI implementation assistance disclosed. Public deployment and real-user feedback remain next steps unless independently completed.”

Timing is approximate; the actual recording includes navigation and load time. Review the video before upload. Do not narrate a public launch, user study, predicted quietness or clinical result that has not happened.
