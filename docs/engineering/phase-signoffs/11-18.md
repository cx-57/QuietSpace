## Visual and adversarial review

Research and visual decisions are recorded in [design direction](../design-direction.md). The redesign replaces the prior repeated rounded cards with indexed venue rows, a coherent warm-paper/ink/rust system, custom arch identity, attributed real photography and self-hosted typography. No generic gradient, glass effects, fake counters/testimonials, decorative chart data or autoplay was introduced.

Codex inspected desktop, mobile, preference and detail screenshots and a frame of the actual captioned recording. Automated axe checks found insufficient contrast in small venue index numerals; the color was corrected and the final suite passes. Mobile filters now collapse through a named, keyboard-operable disclosure so they do not bury search and results.

The real database journey exposed a Next request-wrapper cloning error that the REST test double had not exercised. The local bucket now enters the dependency-injected handler as server-owned context, without cloning/altering the request or trusting client-supplied identity. The production launcher/moderator were corrected for CommonJS interop in `@next/env`, and startup now uses the actual standalone server with copied assets. No failed run is represented as successful evidence.

Additional hardening handles idle database errors without an unhandled process error, preserves an existing custom env file before local setup mutation, excludes private/development files from the Docker context and release trace, and gives cleanup only a time-bounded function capability. The application contains no public moderation route.
